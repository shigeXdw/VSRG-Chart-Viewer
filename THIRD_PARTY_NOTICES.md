- Source: [HURG-IIDX/ITG-Noteskins](https://github.com/HURG-IIDX/ITG-Noteskins/tree/df4e107c8f04064245c377b4166e04876aa72b1a)

The bundled DDR Night assets include excerpts and derived runtime data from the DDR Night noteskin files. The original source README is included as `assets/noteskins/ddr-night/SOURCE-README.md`.

HURG credits [Schneider’s DDR noteskins](https://github.com/SchneiderAFX/Schneiders-DDR-HD-Noteskins), based on [Peter Lawrence’s noteskins](https://github.com/Pete-Lawrence/Peters-Noteskins). ## Branding and preview media

The maintainer supplied the project avatar and confirmed its use with the viewer. Mai Notes hosts the [logo displayed on its viewer buttons](https://mai-notes.com/image/logo.png). The buttons fall back to the site name when the logo cannot load.

The README animations were rendered with the viewer from demo charts. The StepMania preview displays the DDR Night noteskin credited above. Simai and UGC/SUS sprites are generated by the viewer’s drawing code. Simai hitsounds are synthesized. Music, jackets, background videos and charts opened from other sources are supplied by the user or the selected external service.
