## Branding and preview media

The maintainer supplied the project avatar and confirmed its use with the viewer. Mai Notes hosts the [logo displayed on its viewer buttons](https://mai-notes.com/image/logo.png). The buttons fall back to the site name when the logo cannot load.

The README animations were rendered with the viewer from demo charts. The StepMania preview displays the DDR Night noteskin credited above. Simai and UGC/SUS sprites are generated by the viewer’s drawing code. Simai hitsounds are synthesized. The SOUND VOLTEX preview uses standalone Canvas artwork and synthesized sounds. Optional USC skin images come from the local folder selected by the user. Music, jackets, background videos and charts opened from other sources are supplied by the user or the selected external service.
